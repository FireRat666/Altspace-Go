Altspace & Banter game

Go

A synced multiplayer upright Go (Weiqi/Baduk) board. Made for SideQuest / AltspaceVR worlds, and it also works in Banter.

There is no server: players stay in sync through the space's shared state, and the game is plain static files served from go.firer.at.

Add it to an Altspace world

  • On the website: edit your world on altvr.app, open Snippets on the left, choose All, then pick Go.
  • In Unity: add an empty GameObject, click Add Component > BS > Snippet and type go.

Add it with a script tag

Paste this into a Banter space's HTML, or into an Altspace world's Assets/WebRoot/index.html (outside the snippet section). Give each copy its own instance to have more than one game in a space.

Script tag
<script src="https://go.firer.at/Go.js" position="0 1.5 2" board-size="13"></script>

All the settings are listed on GitHub.

A position of 0 0 0 means automatic: the reset button, pass button and scoreboard sit in their default spots next to the board, which follow board-size. Any other value places them relative to the board.

Features

  • Captures, suicide prevention and the ko rule
  • Pass and reset buttons, and a capture scoreboard
  • 19×19, 13×13 or 9×9 boards
  • Several independent boards in one world

How to play

  1. Black moves first.
  2. Click an intersection to place a stone.
  3. Surround stones completely to capture them.
  4. Click Pass if you don't want to move. Two passes in a row end the game.
  5. Ko: you can't repeat the board position from the previous turn.
